# College Resource & Study Booking System

## Overview
A JavaFX desktop application developed for the Advanced Programming Group Project.

The system allows students, staff, and administrators to manage college resources and study bookings.

## Features

- User Login
- Role-Based Access (Student, Staff, Admin)
- Resource Management
- Booking Management
- Booking Approval
- Search & Filter Resources
- File-Based Data Storage
- Admin Dashboard
- Custom Exception Handling

## Project Structure

```
src/
 ├── main
   ├── java
     ├── com.project.apdesktopapplicaton
       ├── controllers/
       ├── models/
       ├── services/
       ├── utils/
       └── MainApplication.java
   module-info.java
  ├── resources
     ├── com.project.apdesktopapplicaton
       └── fxml files
```

## Requirements

- JDK 17
- Maven 3.9+
- JavaFX 21

## How to Run

1. Clone the repository

```bash
git clone [https://github.com/your-username/your-repository.git](https://github.com/Prabesh2-004/AP-Desktop-Application.git)
```

2. Open the project in IntelliJ IDEA.

3. Reload the Maven project.

4. Run `MainApplication`.
